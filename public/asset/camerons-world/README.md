# Cameron’s World scenery

Selected original files from https://www.cameronsworld.net/, sections 10–12,
retrieved on 2026-09-22 for the requested sunset/ocean collage. Original filenames
and bytes are retained. `manifest.json` records source URLs, sizes, dimensions,
frame counts and SHA-256 checksums. `12/bg-still.png` is the only derived file:
the first frame of `12/bg.gif`, used for reduced-motion preferences.

Cameron Askin assembled the source collage using graphics from archived GeoCities
pages. The site footer links to that source. Attribution does not establish a
blanket license for the individual historical graphics; this directory does not
claim one. No remote images or source-site scripts are loaded at runtime.
